# Help Desk Ticketing System

A web application for submitting, tracking, and managing IT support tickets.

## Features
- Submit new tickets with title, description, and priority level
- View all tickets in a table
- Update ticket status (Open, In Progress, Resolved)
- Dashboard showing ticket counts by status

## Built With
- Python
- Flask
- SQLite
- HTML/CSS

## How to Run
1. Install Flask: pip install flask
2. Create the database: python database.py
3. Run the app: python app.py
4. Open http://127.0.0.1:5000 in your browser
